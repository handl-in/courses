## Reading order

For new readers: M1 → M18 in order. Each module assumes the disciplines from prior modules. Sam's narrative arc runs continuously across all 18.

For specific problems (per the Module 18 reading guide):
- **New project:** M1 → M2-M3, then M13 to determine if multi-agent applies
- **Struggling project:** M11-M12 + M16-M17 (the layers most often missing)
- **Multi-agent design:** M13 → M14 → M15
- **Operational issues:** M16 + M17
- **Tool design problems:** M4 → M5
- **Context bloat / cost issues:** M7 → M8
- **Hallucination issues:** M10 → M11
- **"Agent does the wrong thing":** M12 first
- **"Agent gets stuck or fails weirdly":** M2 + M17
